# JSM TRAVEL — Organic + Social Funnel

## Facebook / Instagram / TikTok
المنشور ليس النهاية؛ كل منشور يجب أن يقود إلى صفحة محددة داخل jsmtravel.net.

## Funnel
Social Post
→ Landing Page
→ Hotel / Trip / Visa / Honeymoon
→ CTA
→ Request Form
→ CRM
→ Follow-up
→ Booking

## أمثلة
- منشور عن فندق → صفحة الفندق مباشرة
- منشور عن الغردقة → صفحة الغردقة
- منشور عن عرض → صفحة العرض
- منشور تأشيرة → صفحة التأشيرة
- منشور شهر عسل → صفحة شهر العسل

## Tracking
استخدم روابط UTM، مثال:
?utm_source=facebook&utm_medium=social&utm_campaign=hurghada_hotels

يجب حفظ:
- source
- medium
- campaign
- landing_page
- referrer
- first_visit
- lead_id

## قاعدة مهمة
لا يتم إرسال كل Social traffic إلى الصفحة الرئيسية إذا كانت هناك صفحة هبوط مطابقة للموضوع.
